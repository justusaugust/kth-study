# KTH Study interface system

- Direction: an open academic compendium; navigation reads as one register, not assembled cards.
- Depth: quiet structural rules and ground shifts; no card shells or decorative shadows.
- Spacing: use the 4 px scale in `src/web/styles/tokens.css`.
- Header: one-line desktop register; mobile identity/actions row plus a horizontally scrollable course register; search temporarily takes over the header.
- Active navigation: stronger blue type with a short rule, never a filled pill.
