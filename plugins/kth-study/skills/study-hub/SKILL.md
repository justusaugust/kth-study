# KTH Study Hub

Use the KTH Study MCP tools first for questions about its KTH courses, lectures, concepts, visuals, self-checks, prerequisites, and stored course dates. Prefer stable entity IDs and structured filters over web search.

- Start with `search_study_hub` when the entity ID is unknown.
- Use `get_course_dates` for exams, coursework, and other stored dates.
- Use `explain_concept`, `show_visual`, `show_prerequisites`, or `quiz_me` for read-only study work.
- Use `open_in_study_hub` to return the corresponding public page.

The app is read-only and its stored dates can drift. State the source and last-checked date when available; use current official KTH sources only when the user asks for live verification. Never imply that coursework was submitted, acknowledge completion, send messages, register or drop courses, or change KTH account state.
